# C06 learner acceptance matrix

Each retained workflow, where the desktop proves it, and what stays with
Academy web. Rust: `crates/desktop-core/tests/academy_program` (production
authority interface, synthetic Academy over TLS). React:
`apps/desktop/src/features/academy/*.test.tsx` (Academy's own pages over the
production desktop transport). Academy: the pinned Academy suites (desktop
lab runner, Home, award toasts, lab section hosts, navigation parity).
Native: `docs/planning/evidence/C06/native-acceptance.json` (C06-N01..N11)
against the synthetic endpoint (`tools/native-acceptance/academy_program.py`).
