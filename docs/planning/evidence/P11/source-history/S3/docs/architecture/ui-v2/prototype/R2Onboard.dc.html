Welcome to Prisma AIRS Desktop

This app is built entirely on Palo Alto Networks’ own public APIs: the same programmatic interfaces any application builder can use. Everything you will see here, from reading a tenant’s security posture to scanning a prompt, is an API call you could make yourself. It exists to show how much those interfaces make possible.

We will walk you through it: connect a tenant with the credentials an integration would use, pick the products you manage, check the connection, and optionally load starter test cases. It takes about five minutes, and you can change everything later.
