# C28 — Tokens, v2 shell behind the flag, Home skeleton

Phase: P09. Status: planned. Required predecessor: C27 and C26.

## Outcome

The new shell (sidebar with tenant switcher, navigation inventory, native shortcuts, palette, toasts, modal stack, theme) renders behind a Rust-owned `ui_variant` flag with a Home skeleton, and the legacy shell is untouched.

## Inputs and dependency gates

C27 specification. Read the [common execution contract](../IMPLEMENTATION-PLAN.md),
[review protocol](../review-protocol.md), and [test catalogue](../test-catalogue.md).
Read the [UI v2 specification](../../architecture/ui-v2/DESIGN-V2.md) and its
companions; the frozen prototype under `docs/architecture/ui-v2/prototype/` is
an immutable input. Freeze all source/shared dependency inputs.

## Milestones

1. `ShellSnapshot.ui_variant` and `onboarding` fields; `FeatureId::{Home, Inbox}`; one navigation inventory (label, shortcut index, sidebar membership, availability) consumed by the native menu, sidebar and palette; `navigate` intent; ts-rs regeneration.
2. `apps/desktop/src/styles/tokens.css` per tokens.md; `data-theme` from the observed appearance; no inline colours.
3. Shell components: sidebar (collapsing below 1280px), tenant switcher (switch intent only; guard dialog deferred to C30 but the refusal type is defined), palette, toast system (kinds, expiry, Reduce Motion persistence), modal stack with aria-hidden siblings, Home title row and read-status line placeholder.
4. React root switches on `ui_variant`; legacy shell unchanged; existing feature views mount inside the new shell as-is where they already exist.
5. Fixtures for boards R2Palette, R2Tenants, R2Dark; copy.ts for the shell.

## Required acceptance

- Invariants I8, I9, I10 with tests V2-T09, T10, T11 and native checks V2-N03, N04, N05.
- Minimum window 1180×720; no horizontal scroll at 1180 wide at 200% zoom.
- T09 native keyboard/focus/accessibility checks for every changed UI; the four accessibility additions in DESIGN-V2 §8 are in `native-checks.json` for C28.
- Screenshot evidence set at 100% and 200% in both themes under `evidence/C28/screens/`.

Controller runs, native record, screenshots, Codex review (D034: may complete at 8 with no blockers; raised to 9 before P09 review).
