1. Pin Rust/Tauri/React/build tooling and clean external source inputs; establish independent v2 bundle/data/protected-storage identities.
2. Implement the documented workflow controller, receipt schema, narrow fingerprint exclusions, and exact check/test/native/package command manifests.

## Required acceptance

- desktop-host ipc_admission/permission_manifest targets exercise wrong-window/origin, finite DTO/size limits, CSP/application-command grants and exclusion of fixture commands from production.

- Controller uses crates/xtask and argv-only checks.json; immutable Academy input is copied to scratch with scripts disabled/allowlisted. Both consumers pass scoped presentation suites without hosted/DB setup; changed Git configuration fails the gate.

- Any changed UI also requires T09 actual native keyboard/focus/accessibility checks; global requirements are not deferred solely to C24.

- T08,T09,T19: actual native shell, theme/keyboard/focus behavior, no startup remote calls or Academy account effects.
- Controller rejects score8 in any dimension, required fixes despite score9, missing/stale/tampered receipts, changed dependency/build flags, and skipped checks.
- Clean macOS checkout builds locked inputs; shared Academy web and desktop consumer checks pass; no absolute developer path required at runtime.

G01/C01 must bind these assertions to exact commands and fixture/native targets
before execution. Run appropriate regressions when changes reach earlier chunks.
