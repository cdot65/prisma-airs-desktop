Phase: P09. Status: planned. Required predecessor: C26 is not required; C27 is docs and controller registration only and may proceed in parallel with C26 (D058).

The reviewed "Refined Native" prototype (canvas version 134) is extracted into a specification the remaining P09 chunks are judged against, and the review controller recognises P09.

## Milestones

1. Write `docs/architecture/ui-v2/`: DESIGN-V2, tokens, state ownership, invariants with test ids, screen contracts, provenance, frozen prototype with manifest.
2. Write chunk instructions C28–C34, the P09 row in the implementation plan, the chunk index, the status row and D058.
3. Register P09 in the controller: `Subject` accepts C27–C34 and P09; `checks.json` gains C27–C34 entries and P09; C27 is marked `docs_only`, which the controller enforces as: no native-prepare run, no native inventory or acceptance (also excluded from P09's integrated native members), and owner acceptance below 9/10 refused at completion and at completion recognition. Application chunks keep every gate: a missing or empty native inventory still fails, and marking an application chunk `docs_only` is rejected by manifest validation. Production controller paths and these refusals are tested.
4. Request independent Codex review of the specification at the 9/10 bar.

## Required acceptance

- The specification assigns every prototype state field (state-ownership.md), names twelve invariants each with at least one test id, and lists every deviation from the prototype in provenance.md.
- `cargo test -p xtask --lib` and the `shell_controller` suite pass with the controller changes; `Subject::parse("C34")` and `"P09"` succeed; `"C35"` and `"P10"` are refused; `required_runs(C27)` has no native-prepare; `owner_acceptance_allowed(C27)` and `(P09)` refuse; `native_members(P09)` excludes C27; mutation "application chunk marked docs_only" is rejected.
- The specification maps every product, tab and action to an admitted service or marks it unavailable (DESIGN-V2 §6); the state inventory lists every `s.*`, `ts.*` and `f.*` key of the frozen prototype; every behavioural deviation is in provenance.md with its owning chunk.
- No application source outside `crates/xtask` and the checks/native-checks manifests changes in this chunk.

## Evidence and completion

Review packet for C27 under `reviews/C27/`. Require ≥9/10 overall and in every dimension (this chunk is excluded from the D034 8/10 allowance because every later chunk depends on it). Preserve attempts, raw verdicts, hashes and remediation. Commit only the reviewed tree.

Docs and controller only.
