# C30 — Inbox, reads, tenant switch guard, Home attention

Phase: P09. Status: planned. Required predecessor: C29.

## Outcome

Inbox items, reads and acknowledgments are core-owned per tenant; the single tenant-switch path refuses while a Harness decision is pending; Home shows attention and read status from the same scopes.

an immutable input. Freeze all source/shared dependency inputs.

1. Scopes `InboxItem`, `ReadStatus`; intents `readTenant`, `recheckProduct`, `acknowledgeItem`, `snoozeItem`, `unsnoozeItem`, `switchTenant{resolution?}` with `SwitchBlocked` refusal.
2. Inbox screen (tabs, rows, detail pane, contextual action targets), Home attention list and read-status line, completion toasts derived from `ReadStatus` transitions, guard dialog rendered from the refusal.
3. Snooze return times computed in core; one `snoozeLabel` shared by Home and Inbox.
4. Fixtures for R2Inbox and the fresh-tenant state.
