## Milestones

1. Implement profiles/topics/application mutations and key create/add-version/rotate/delete where v1 supports them.
2. Prepare exact before/after reviews bound to tenant, credential epoch, resource version and draft; consume approval once.
3. Keep one-time secrets in a protected explicit reveal/capture flow; never include them in general logs, caches or Harness results.

5. Keep existing customized PI/directionality preview options explicitly local/unavailable for Apply unless a separate scope decision and verified contract promote them. Negative wire tests prove preview fields are not silently submitted.
