# C07 — Academy encrypted offline work

Phase: P02. Status: planned. Required predecessor: C06.

## Outcome

Preserve downloaded learning and draft continuity without offline grading or action replay.

## Inputs and dependency gates

C06; versioned desktop bundle/lease/draft/submission contracts.

Read the [common execution contract](../IMPLEMENTATION-PLAN.md),
[review protocol](../review-protocol.md), and [test catalogue](../test-catalogue.md).
Concrete interfaces follow accepted G01 ADRs. Freeze all source/shared dependency
inputs; active neighboring worktrees and unavailable methods cannot count as pins.

## Milestones

1. Implement account-scoped encrypted bundle/draft storage, lease/revision checks, bounded media/content retention and crash-safe writes.
2. Support offline reading/drafting and explicit online submission; normal auth refresh does not replay deferred actions.
3. Lock work on sign-out, revalidate account/access/withdrawn revisions on reconnect, and preserve legitimate saved work.
4. Disclose unavailable offline media/motion; never bundle authored server-private content to fill a gap.

## Required acceptance

- Any changed UI also requires T09 actual native keyboard/focus/accessibility checks; global requirements are not deferred solely to C24.

- T06,T11,T12: lease expiry, wrong account, withdrawn revision, vault denial/corruption, interrupted save/restart and duplicate submission.
- Network-capture fixture proves no automatic grading/progress/business action upon reconnect.
- Native offline launch/read/edit/close/relaunch/account-lock flow, with bundle size and retention limits verified.

G01/C01 must bind these assertions to exact commands and fixture/native targets
before execution. Run appropriate regressions when changes reach earlier chunks.
No test result, native acceptance, or live qualification is claimed by this file.

## Evidence and completion

Encrypted-file and content-inventory evidence, recovery tests, native offline matrix and redacted storage manifests.

Use the [implementer prompt](../prompts/implement-chunk.md) and
[independent reviewer prompt](../prompts/review-chunk.md). Require ≥9/10 overall
and in architecture, behavior, authority/security, and validation; no required

remediation. Commit only the reviewed tree; do not unlock the next chunk early.

## Safety and recovery

Use synthetic bundles/drafts. Rollback preserves encrypted user work; no plaintext downgrade or automatic delete on failed migration.
