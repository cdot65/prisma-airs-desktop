# Prisma AIRS Desktop v2

Planning-stage successor to Prisma AIRS Desktop: React presentation in Tauri,
a focused Rust application core, the native Rust SCM SDK, and shared Academy
presentation. First target: macOS Apple Silicon, distributed as a signed and
notarized DMG. No application implementation exists in this checkout yet.

Start with the [implementation plan](docs/planning/IMPLEMENTATION-PLAN.md),
[26 chunk instructions](docs/planning/chunks/README.md),
[planning record](docs/planning/README.md),
[accepted decisions](docs/planning/decisions.md),
[v1 feature baseline](docs/planning/feature-baseline.md), and
[source evidence](docs/planning/source-evidence.md).

The sequence is interview and detailed Markdown plan, architecture improvement
review, then implementation and independent reviews, testing, installed-artifact
validation, and signing. Do not skip the planning or architecture gates.
